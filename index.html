安装

三条命令，
桌面就多一只宠物。

# 需要 macOS 14+、Xcode 15+、XcodeGen
xcodegen generate
xcodebuild -project Pawly.xcodeproj -scheme Pawly \
  -configuration Debug -derivedDataPath build build
open build/Build/Products/Debug/Pawly.app

# 把钩子接进 Claude / Codex / Gemini
Pawly.app/Contents/MacOS/Pawly --install-hooks

首次打开 提示「Pawly.app 已损坏」？这只是 macOS 对未签名应用的拦截，文件没坏。把 Pawly 拖进「应用程序」后，在终端运行下面这行去掉隔离标记，之后双击即可正常打开： 

xattr -dr com.apple.quarantine /Applications/Pawly.app

提示 Vibe Island 用户：安装前先退出 Vibe Island——它会在移除约 1 秒后重新写回自己的钩子，两个应用会打架。

把它放上桌面。

让你的编程 agent，从此有张脸。
